# Export provenance and scope

These outputs were freshly generated and verified from user-supplied hash-matched original media using framework commit `9269d4a3f7893ae6139e64f7e811c5e2329a3ede`. Project-authored analysis/labels/types/comments remain in the framework; this repository contains the resulting rendered exports, not duplicate journals or import recipes.

Five disassembly listings and two Starglider II platform wrappers reproduce six exact decoded payloads. The listings represent original instructions and can also contain inline original data. The 39 INCBIN files (206,400 bytes total) match exact spans of the verified original members. FOFT music-9 is an embedded 50,000-byte span of main, not a separate assembly owner. Conqueror is retail SPS 1275's gameplay resident, not the Quartex ADF variant. Starglider II uses a shared listing with platform wrappers; the recovered Atari ST program was independently checked from the pinned STX.

## Include normalization

The private 84-file baseline included 25 SDK-header copies. They are not shipped here. Four minimal generated constants includes replace them; only SDK INCLUDE directives changed in the four affected listings. All other source-line text, annotation content and all INCBIN assets were preserved. CRLF line endings in the Conqueror listing were normalized to LF. Constants are resolved values for names actually used by the listings, obtained from the successful assembler symbol tables against the original include snapshot. They do not contain the SDK's macros or prose. Every normalized build matches its baseline bytes. The existing three Starglider II symbol includes are generated by the framework's platform projection.

The source interface snapshot was Amiga 2.04 Includes V37.4 (NDK 2.0). Original SDK notices are preserved in each generated constants header:

- (C) Copyright 1985-1991 Commodore-Amiga, Inc.
- All Rights Reserved

The headers' notices identify the source interface; this document does not select or replace any third-party license. The assembler and full SDK are not distributed. The framework retains the tested reference-derived support and its source/provenance information.

## Verification boundary

Each advertised output assembles with only this checkout, Python's standard library and external vasm, and is checked against its expected size and SHA-256. This is program/member proof, not whole-media reconstruction or emulator boot qualification. No original media, compiled payload, private logs/evidence, credentials or development-tool binaries are repository files.
